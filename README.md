# 灵感提取 Skill

一个用于内容工作流的 Codex Skill 总入口。

它会根据平台指令，把任务路由到合适的内容提取方式：

- 抖音：调用本地「文案抓取」流程，提取口播、逐字稿、内容结构、钩子和可复用话术。
- 小红书：调用 agent-reach / xhs-cli，读取笔记正文、搜索结果、评论和公开内容。
- 小红书视频：先读取公开文本和评论，如需口播，再结合文案抓取兜底。
- B站 / YouTube / 网页 / RSS：可通过 agent-reach 进行内容读取和字幕/转写。

## 使用场景

- 抖音 / 小红书内容灵感提取
- 对标视频和笔记拆解
- 评论区洞察整理
- 选题角度提炼
- 爆款结构分析
- 口播文案复盘和改写前素材准备

## 示例指令

灵感提取：抖音 <完整抖音分享文本>

灵感提取：小红书 搜一下 装修避坑

灵感提取：读这个小红书链接 <链接>

灵感提取：看一下这个小红书笔记的评论 <链接>

## 依赖

这个 Skill 是一个路由型入口，建议配合以下工具使用：

- agent-reach
- xhs-cli
- 本地「文案抓取」Skill
- yt-dlp
- ffmpeg
- Whisper 或其他 ASR 工具

## 注意事项

- 不包含任何平台 cookie、登录信息或私有数据。
- 不绕过平台权限、登录、反爬或私密内容限制。
- 抖音视频下载和转写建议使用临时目录，避免长期占用本地存储。
- 豆包等 AI 输出如果是创作稿，不能当作原视频逐字稿。
